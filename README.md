# ImageText FindSearcher

Android app that finds words **inside your pictures** – screenshots of Facebook posts, chats, web pages.

## Download
👉 [Download the latest APK](https://github.com/KasparsKalkis/imagetext-findsearcher/releases/latest)

## Features
- Choose one or more picture folders to search
- Several words: **All words (AND)** or **Any word (OR)**, phrases in "quotes"
- Ignores upper/lower case and (optionally) accents: é = e, š = s
- Results with thumbnail, full file path, date and time created, text snippet
- Tap a result – the image opens with **frames around the found words**
- Progress bar and Cancel button
- Copy results to clipboard or save as CSV
- Recognized text is remembered – repeat searches are instant

## Privacy and safety
- Pictures are only **read** – the app cannot change, move or delete files
- **No internet permission** – nothing leaves your phone
- Text recognition runs on the phone (Google ML Kit)

## How to install
1. Download the `.apk` file from the link above on your Android phone (Android 10 or newer)
2. Open it and allow installing from this source when asked
3. If Play Protect warns about an unknown developer, choose "Install anyway"
4. When the app asks for photo access, choose **"Allow all"**
